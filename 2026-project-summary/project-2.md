# Project 2

## SVHN Digit Recognition

### Description

The SVHN (Street View House Numbers) Digit Recognition project introduced me to the field of **Deep Learning** and image classification. The objective was to develop a Convolutional Neural Network (CNN) capable of recognizing handwritten digits extracted from real-world street images. Unlike traditional tabular datasets, the SVHN dataset consists of thousands of color images containing digits collected from house numbers in Google Street View, making the classification task more challenging.

This project allowed me to gain practical experience with computer vision techniques and understand how deep learning models automatically learn features from images.

### What I Did

During this project, I completed the following tasks:

- Loaded and explored the SVHN image dataset.
- Preprocessed the images by resizing, normalizing pixel values, and preparing them for training.
- Built a **Convolutional Neural Network (CNN)** for digit classification.
- Configured the network architecture, including convolutional, pooling, activation, and fully connected layers.
- Trained the model using the training dataset.
- Evaluated the model on a separate testing dataset.
- Measured prediction accuracy and analyzed the model's performance.
- Tested the trained model on unseen images to verify its generalization capability.

### Skills Learned

This project helped me develop knowledge in several areas of Deep Learning and Computer Vision, including:

- Image preprocessing
- Convolutional Neural Networks (CNNs)
- Deep Learning fundamentals
- Image classification
- Model training and validation
- Performance evaluation
- TensorFlow/PyTorch workflow
- Working with large image datasets

### Challenges

Compared to previous machine learning projects, this project introduced several new challenges. Processing image data is significantly more complex than working with tabular datasets because images contain thousands of pixel values that must be properly normalized before training.

Another challenge was understanding the architecture of Convolutional Neural Networks. Learning the purpose of convolutional layers, pooling layers, activation functions, and fully connected layers required additional study beyond classroom lectures. Training the network also required experimenting with different parameters to obtain satisfactory accuracy while avoiding overfitting.

### Outcome

This project strengthened my understanding of Deep Learning and demonstrated how neural networks can automatically extract meaningful features from images. It served as an important step toward more advanced Computer Vision projects, including face detection and object detection using the YOLO architecture.
