# Project 1

## Iris Flower Classification

### Description

The Iris Flower Classification project was one of my first practical experiences with Machine Learning. The objective was to develop a classification model capable of predicting the species of an iris flower based on four botanical measurements: **sepal length, sepal width, petal length, and petal width**. The project used the well-known **Iris dataset**, which contains three flower species: **Iris-setosa**, **Iris-versicolor**, and **Iris-virginica**.

This project introduced me to the complete supervised machine learning workflow, from data exploration to model evaluation, and served as a foundation for more advanced AI projects completed later in the semester.

### What I Did

During this project, I completed the following tasks:

- Explored the Iris dataset to understand its structure, features, and class distribution.
- Performed **Exploratory Data Analysis (EDA)** using statistical summaries and visualizations.
- Checked the dataset for missing values and prepared it for training.
- Split the dataset into **training** and **testing** sets to evaluate model performance on unseen data.
- Trained several supervised classification algorithms.
- Evaluated model performance using **accuracy** and compared the prediction results.
- Created visualizations to better understand feature distributions and the relationships between the three classes.

### Skills Learned

This project helped me build a strong foundation in Machine Learning by introducing concepts such as:

- Supervised Learning
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Feature analysis
- Train-test splitting
- Model training
- Model evaluation
- Data visualization using Python

### Challenges

Although the Iris dataset is relatively simple, the biggest challenge was understanding the complete machine learning pipeline rather than simply writing code. I had to learn why each preprocessing step is necessary, why the dataset must be divided into training and testing sets, and how evaluation metrics indicate whether a model has learned effectively.

Another challenge was becoming familiar with Python libraries such as **Pandas**, **NumPy**, **Matplotlib**, and **Scikit-learn**. Learning how these libraries work together required reading documentation, experimenting with different functions, and debugging errors throughout the development process.

### Outcome

This project successfully introduced me to the practical workflow of supervised machine learning. It provided the knowledge and confidence needed to tackle more advanced projects later in the semester, including image classification, computer vision, natural language processing, and medical diagnosis systems.
