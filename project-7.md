# Project 7

## Patient Management System

### Description

The Patient Management System was a Python application designed to manage patient records efficiently through a simple and organized interface. The objective of the project was to simulate a basic healthcare management system capable of storing, updating, retrieving, and deleting patient information.

This project focused on applying **Object-Oriented Programming (OOP)** principles to design a modular and maintainable application. It also reinforced fundamental software engineering concepts such as data organization, code reusability, and program structure.

### What I Did

During this project, I completed the following tasks:

- Designed a system to store and manage patient information.
- Implemented features to add new patient records.
- Developed functionality to update existing patient information.
- Created methods to delete patient records when necessary.
- Displayed patient information in an organized format.
- Applied **Object-Oriented Programming (OOP)** concepts by creating classes, objects, and methods.
- Organized the project into reusable and maintainable modules.
- Tested the application to ensure each operation functioned correctly.

### Skills Learned

This project helped me strengthen my programming and software engineering skills, including:

- Python programming
- Object-Oriented Programming (OOP)
- Classes and objects
- Encapsulation
- CRUD (Create, Read, Update, Delete) operations
- Data management
- Modular programming
- Code organization and maintainability

### Challenges

The main challenge of this project was designing a clean and maintainable program structure while applying Object-Oriented Programming principles effectively. I had to determine how to organize classes and methods so that each component had a clear responsibility and the overall system remained easy to understand.

Another challenge was ensuring that the CRUD operations interacted correctly with the stored patient data while avoiding code duplication. This project taught me the importance of writing modular code that can be easily extended as new features are added.

### Outcome

This project improved my understanding of Object-Oriented Programming and demonstrated how software engineering principles can be applied to develop structured applications. By implementing a complete patient management system, I gained practical experience in designing reusable code, organizing data efficiently, and building maintainable software.

The knowledge acquired through this project provides a strong foundation for developing larger management systems and backend applications in the future.
