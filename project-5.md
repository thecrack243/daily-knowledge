# Project 5

## Heart Disease Prediction

### Description

The Heart Disease Prediction project was the most comprehensive Machine Learning project I completed during the semester. The objective was to develop predictive models capable of determining whether a patient is at risk of heart disease based on clinical measurements from the **UCI Heart Disease dataset**.

Unlike my previous projects, this one covered the entire Machine Learning pipeline, from data preprocessing and feature engineering to model training, hyperparameter optimization, evaluation, and deployment. The project also involved comparing multiple machine learning algorithms to determine which model performed best on the dataset.

Through this project, I gained a deeper understanding of how machine learning techniques can be applied to healthcare problems to support clinical decision-making.

### What I Did

During this project, I completed the following tasks:

- Explored and analyzed the UCI Heart Disease dataset.
- Performed data preprocessing to prepare the dataset for training.
- Handled missing values using **median imputation**.
- Standardized numerical features using feature scaling techniques.
- Selected relevant features for model training.
- Split the dataset into training and testing sets.
- Implemented and trained three different machine learning models:
  - Logistic Regression
  - Support Vector Machine (SVM)
  - Multi-Layer Perceptron (MLP)
- Optimized model performance using **Grid Search** and **Optuna** for hyperparameter tuning.
- Applied **cross-validation** to evaluate model robustness and reduce overfitting.
- Compared the performance of the different models using several evaluation metrics, including:
  - Accuracy
  - Precision
  - Recall
  - F1-score
  - ROC-AUC
- Built an interactive inference system capable of predicting heart disease risk based on patient information.
- Organized the project with professional documentation and a well-structured GitHub repository.

### Challenges

This project introduced many advanced Machine Learning concepts that were more complex than those encountered in previous assignments. Understanding the purpose of **cross-validation**, **hyperparameter optimization**, and the differences between multiple classification algorithms required considerable independent study.

Another challenge was learning how to evaluate models using several performance metrics rather than relying solely on accuracy. Understanding metrics such as **precision**, **recall**, **F1-score**, and **ROC-AUC** helped me appreciate the importance of selecting appropriate evaluation methods, particularly for medical prediction tasks.

Training and tuning multiple models also required experimenting with different parameters and carefully analyzing the results. Preparing a clean, organized notebook and documenting the project professionally for GitHub further improved my software engineering and documentation skills.
