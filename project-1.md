# Project 1

## 1. Iris Flower Classification

### Description

This introductory Machine Learning project classified iris flowers into
three species using flower measurements.

### What I Did

-   Explored the Iris dataset
-   Performed data preprocessing
-   Split the dataset into training and testing sets
-   Trained classification models
-   Evaluated model performance
-   Visualized the dataset

### Challenges

Understanding the complete machine learning workflow and the importance
of preprocessing and train/test splitting.
